# 🧮 82MS Scientific Calculator (Java Swing)

A desktop-based **Scientific Calculator** developed using **Java Swing** that performs a variety of mathematical and scientific calculations through an intuitive graphical user interface. The application supports arithmetic operations, trigonometric functions, logarithmic calculations, permutations & combinations, factorials, and maintains a history of calculations for improved usability.

---

## ✨ Features

### Basic Arithmetic
- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- % Modulus

### Scientific Operations
- Power (a^b)
- Factorial
- Permutation (nPr)
- Combination (nCr)
- Sine
- Cosine
- Tangent
- Natural Logarithm
- Base-10 Logarithm

### Logarithmic Calculations
- log(a + b)
- log(a − b)
- log(a × b)
- log(a ÷ b)
- log(a)
- log(b)
- log10(a)

### User Interface
- Java Swing GUI
- Dropdown menu for selecting operations
- Real-time result display
- Calculation history panel
- Clear inputs
- Clear history
- Error handling for invalid calculations

## 🚀 Getting Started

### Prerequisites

- Java JDK 8 or above
- IntelliJ IDEA / Eclipse / NetBeans / VS Code

### Clone Repository

```bash
git clone https://github.com/Saubhagya-M/82MS-Scientific-Calculator-Java-GUI.git
```

### Compile

```bash
javac ScientificCalculator82MS.java
```

### Run

```bash
java ScientificCalculator82MS
```
